# Definition of Done

Uma issue será considerada concluída quando atender aos seguintes critérios:

* O código foi desenvolvido em uma branch própria relacionada à issue.
* A implementação foi revisada e enviada por Pull Request.
* Pelo menos um colega do time revisou e aprovou o Pull Request.
* O código foi integrado à branch `main` somente após a aprovação da revisão.
* O código segue o padrão de organização e qualidade utilizado pelo projeto.
* O Laravel Pint não apresenta erros no código alterado.
* Quando houver regra de negócio, foram criados ou atualizados testes automatizados.
* A funcionalidade foi testada manualmente no navegador quando aplicável.
* Não existem erros conhecidos que impeçam o funcionamento da funcionalidade.
* A documentação foi atualizada quando a alteração exigir alguma mudança na documentação.
* A issue possui os critérios de aceite atendidos.
* Os commits são pequenos e possuem mensagens que descrevem claramente as alterações realizadas.

## Fluxo de trabalho

1. Criar uma branch específica para a issue.
2. Implementar a tarefa em commits pequenos.
3. Executar os testes necessários.
4. Verificar a qualidade do código.
5. Abrir um Pull Request relacionando-o à issue.
6. Solicitar a revisão de pelo menos um colega.
7. Corrigir os problemas apontados na revisão, quando necessário.
8. Após a aprovação, realizar o merge para a `main`.

Uma tarefa só será considerada **Done** quando todos os critérios aplicáveis acima forem atendidos.
